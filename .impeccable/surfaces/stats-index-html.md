# App statistics

Mode: Operate. This route extends the established personal site's visual system.

## Direction contract

THESIS: Start with Anders's requested DAU, MAU, session and event counts, then let
him trace those numbers into daily graphs, distributions, event dimensions and
individual session timelines. Private data always comes from the authenticated API.

OWN-WORLD: Inherit assets/style.css: sage-tinted ground, teal interaction color,
ink foregrounds, light/dark system preference and the existing display/body stacks.
Use familiar forms, tabs and tables, with tabular numerals for measurement.

STORY: Sign in with the allowed Google account, choose an app and UTC window,
inspect activity, then narrow dimensions or open a session. Coverage makes missing
instrumentation and migration work visible. Partial queries never imply exact totals.

FIRST VIEWPORT: Compact site/account header; app rail on desktop, horizontal app
navigation on mobile; title, date form and investigation tabs above four inline
headline measures. The activity plot leads the deeper content. Its measure switch
is the signature interaction: events, active installations and sessions share the
same exact daily data, available as a table too.

FORM: Established site extension with a conventional exploration workspace,
inspired by the user's Fuse Games reference. seed: none (incumbent extension).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No shipping raster assets are introduced. Existing tokens remain the design
authority; no durable replacement visual system is proposed. The detector's sole
tight-leading warning is on the short entry display heading, not body copy.
