# The Haunted Garden

Public app: https://andeplane.github.io/personal/halloween/

A buildless browser for 20 researched home Halloween displays. Source files are served directly by the repository's existing GitHub Pages workflow.

Features: search, theme filters, sorting, enlarged photos, selected animated previews, original source links, a saved shortlist, per-idea notes and Markdown export.

Favourites and notes use browser local storage. They do not sync across devices or transfer from the earlier private Sites origin. Photos remain hosted by their original publishers, with source links and credits in every detail view.

Check JavaScript with `node --check halloween/app.js` and `node --check halloween/ideas.js`. All app asset links are relative so the app works at the GitHub Pages subpath.
